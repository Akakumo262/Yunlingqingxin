# 云岭青心 · 学生端 / 家长端评审分享版

这是给同事评审页面结构和产品细节的静态版本，不连接后端，不需要 Node.js、数据库或安装依赖。

## 怎么打开

1. 把整个 `分享评审版-学生端-家长端` 文件夹打成压缩包发送。
2. 同事解压后，双击 `index.html`。
3. 在首页选择“学生端”或“家长端”。
4. 页面中的导航、筛选、意见记录可以直接点击体验。

所有资源都是当前文件夹内的相对路径，直接使用 `file://` 打开即可。

## 评审重点

- 哪些模块对学生或家长最有用？
- 首页信息是否太多，入口是否容易找到？
- “发现”里的 AI 资讯、竞赛和志愿活动还需要哪些筛选条件？
- 家长摘要是否清楚表达了隐私边界？
- 哪些文案、按钮、提示或页面顺序需要修改？

## 意见记录

每个端页面底部有“意见记录”区域。提交的意见只保存在当前浏览器的本地存储中，方便临时评审，不会上传服务器。需要汇总时，请同事复制意见内容或截图。

## 当前边界

- 页面数据是演示数据。
- 登录、接口、数据库、真实推送和真实报名都没有接入。
- 外部资讯按钮只用于展示“跳转原文”的交互方向。
